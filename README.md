# Meals

Our family recipe box and monthly dinner planner.

- **Recipes** in a clean cooking format: amounts inside each step, a servings scaler, cook mode, print and share by text
- **Ratings and dated notes** for every recipe
- **Monthly planner** with leftovers and restaurant nights *(coming next)*
- **Grocery run** for the next seven days *(coming next)*

The site's code lives here. Recipes, notes and plans live in Firebase behind sign-in, not in this repository.

`data/sample-recipes.js` holds three sample recipes for previewing the layout.
